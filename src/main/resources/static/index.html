もじメーターの使い方

もじメーターは、レポート、応募書類、論文、作文など、文字数の上限が決まっている文章の確認に使える無料ツールです。文章を入力すると、現在の文字数と上限に対する割合がリアルタイムで表示されます。

  1. 「上限文字数」に提出先から指定された文字数を入力します。
  2. 文章を入力し、現在の文字数とメーターを確認します。
  3. 上限の90%に到達すると「9割達成！」と表示されます。
  4. 必要に応じて一時保存、履歴からの呼び出し、本文のコピーを利用します。

文字数カウント方式について

提出先によって、改行や空白を文字数に含めるかどうかが異なる場合があります。もじメーターでは、文章の用途に合わせて3つの方式を選択できます。

  • 改行・空白をカウント：入力内容をそのまま数えます。
  • 改行をカウントしない：段落の改行を除いて数えます。
  • 改行・空白をカウントしない：空白文字を除いて数えます。

実際の提出時は、提出先が指定する文字数の数え方を必ず確認してください。

こんな文章に活用できます

レポート・論文

文字数制限のある授業レポートや研究概要の分量を確認できます。

応募書類

エントリーシートや志望動機など、指定文字数に合わせて文章を整えられます。

作文・小論文

試験や課題で指定された上限文字数への到達状況を確認できます。

よくある質問

入力した文章はサーバーに保存されますか？

一時保存機能では、文章は利用者のブラウザ内に保存されます。運営者のサーバーには保存されません。

スマートフォンでも使えますか？

スマートフォンやタブレットのブラウザにも対応しています。

9割を超えたら提出してよいですか？

9割到達は文章量の目安です。提出前には、内容、誤字脱字、提出先の指定条件も確認してください。
